## プロパティのルール

| 項目 | プロパティ名 | 値の型 | ルール |
|---|---|---|---|
| 商品名 | `name` | 文字列 | |
| 店名 | `shop` | 文字列 | |
| 区分 | `category` | 文字列 | 「餃子」「サイド」「スイーツ」「ドリンク」のいずれか |
| 個数 | `pieces` | 整数 または `null` | 餃子料理は1皿に入っている個数を入れる。それ以外は `null` |
| 価格 | `price` | 数値 | 税込の金額（円） |
| アレルゲン | `allergens` | 文字列の配列 | 「えび」「かに」「くるみ」「小麦」「そば」「卵」「乳」「落花生」の8品目から選ぶ。含まない場合は空の配列 `[]` |
